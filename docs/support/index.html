Reconnect Cable Guide

Support

Reconnect Cable Guide helps document device ports, cables and reconnect steps before equipment is unplugged.

Common Tasks

  • Create a setup from the main Reconnect screen.
  • Add each device in the setup.
  • Add or capture photos for each device.
  • Mark ports directly on the device photo.
  • Add cables and connect each cable between two ports.
  • Use Reconnect Mode to reconnect one cable at a time.
  • Export a PDF guide or .reconnect package from the setup actions menu.
  • Restore purchases from Settings or the Upgrade screen.

Troubleshooting

  • If camera capture is unavailable, confirm the device has a camera and Camera permission is enabled in iOS Settings.
  • If a photo cannot be selected, try choosing a smaller image or restarting the app.
  • If OCR misses a port label, add the port manually from the device's Port Annotation section.
  • If an imported package is rejected, export the setup again from the original device and avoid renaming files inside the package.
  • If a purchase does not appear, use Restore Purchases while signed in with the Apple ID that made the purchase.

Contact

When requesting support, include:

  • App version
  • iOS or iPadOS version
  • Device model
  • A short description of the issue
  • The steps that caused the issue

Do not send private serial numbers or photos unless you choose to include them.
